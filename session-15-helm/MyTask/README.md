## What is Helm?

Helm is the package manager for Kubernetes.

It simplifies deployment and management of Kubernetes applications using Helm Charts.

Benefits:
- Reusable templates
- Easy upgrades
- Easy rollbacks
- Version management
- Environment-specific configurations

--------------------------------

## helm create

Purpose:
Creates a new Helm chart.

Command:
helm create myapp

Result:
A chart structure was generated.

--------------------------------

## helm install

Purpose:
Deploys a Helm chart.

Command:
helm install myapp-release ./myapp

Result:
Application successfully deployed.

--------------------------------

## helm list

Purpose:
Lists installed releases.

--------------------------------

## helm uninstall

Purpose:
Removes Helm release.
